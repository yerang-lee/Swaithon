# 장보소

React Native + Expo + TypeScript 앱입니다.

```sh
cd frontend
npm install
npm start
```

웹 미리보기: `npm run web` / 타입 검사: `npm run typecheck`

시작 화면은 로그인이고 회원가입 링크로 이동할 수 있습니다.
인증 API, 비밀번호 재설정, 약관 본문은 추후 연결해야 합니다.

초록 버튼은 `frontend/src/components/ui/PrimaryButton.tsx`를 재사용합니다.
메인 색상 `#53B175`, 버튼 radius `19`를 공통 테마에 정의했습니다.
상세 폴더 설명은 `frontend/STRUCTURE.md`를 참고하세요.
