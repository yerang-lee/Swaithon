# 상품 가격 변동 그래프

사용자 제공 명세: GET /products/{listing_id}/price-history, 양의 정수 listing_id, Bearer 인증. 가격은 해당 가게의 해당 판매 게시물 이력만 사용합니다. 서버 current_price를 현재 가격으로 표시하고, price_history의 오래된 순서 및 정수 가격·ID·날짜를 검증합니다. 시장 평균이나 임의의 현재 시점 기록을 추가하지 않습니다.

상품 상세에 1주일/1개월/3개월/전체 기간 선택과 선 그래프를 표시합니다. 기간은 조회 시점 기준 프론트 필터이며 API에 별도 쿼리를 추가하지 않습니다. 날짜는 KST로 표시하고 그래프 터치 시 해당 가격을 그래프 아래에서 확인합니다. 날짜·가격 가로 스크롤 목록은 표시하지 않습니다. 기간 내 이력이 없으면 현재 가격 및 안내를 표시하고, 이력이 하나면 점 하나를 표시합니다. 로딩/오류/재시도는 상품 본문과 분리합니다. 상품 전환이나 재조회 후 이전 응답은 무시합니다.

명시적 테스트 로그인은 테스트 서버의 예시 가격 이력을 사용합니다. 미리보기 상품은 실제 API를 호출하지 않습니다. 실서버는 가격 변경 시 저장 및 할인 여부에 따른 실제 가격 산정을 담당합니다. 실기기 터치 동작과 실제 서버 연동은 별도 확인이 필요합니다.
