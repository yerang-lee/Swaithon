# 가격 비교 API 제안 (보관용)

현재 구현은 사용자 제공 확정 명세인 GET /products/{listing_id}/price-history를 따릅니다. [현재 구현 문서](price-history.md)를 참고하세요. 아래 시장 평균·기간 쿼리 제안은 구현에 사용하지 않습니다.

## 역할

백엔드: 가격 변경 시 이력 저장, 동일 규격 상품 분류, 시장 평균 계산, 기간별 조회 API.
프론트엔드: 조회 요청, 날짜/가격 축과 점포/시장 평균 두 선 표시, 로딩/오류/데이터 없음 처리.
프론트가 현재 상품 목록을 모아 과거 가격이나 시장 평균을 추측해서 만들지 않습니다.

## 제안 경로와 응답

`GET /products/{product_id}/price-history?days=30`

```json
{
  "product_id": 101,
  "store_id": 10,
  "market_id": 1,
  "currency": "KRW",
  "unit_label": "1kg",
  "timezone": "Asia/Seoul",
  "points": [
    { "date": "2026-11-01", "store_price": 8000, "market_average_price": 8500, "market_sample_count": 4 },
    { "date": "2026-11-02", "store_price": 7500, "market_average_price": null, "market_sample_count": 0 }
  ]
}
```

이는 백엔드와 협의할 제안이며 현재 앱에서 이 경로를 호출하지 않습니다.

## 백엔드 구현 시 합의할 기준

- 상품명 문자열만 비교하면 품종/등급/포장 수량이 섞입니다. 공통 상품 분류 ID와 규격(무게/개수/등급)을 기준으로 묶고 같은 단위로 환산합니다.
- 가격 이력에 상품/점포/시장/기본 가격/할인 가격/할인 적용 여부/변경 시각/판매 상태를 남깁니다. 현재 가격 덮어쓰기만으로는 과거 그래프를 만들 수 없습니다.
- MVP 제안: 한국 시간 기준 각 날짜의 마지막 유효 판매가를 점포별로 하나씩 구하고, 같은 시장·같은 규격 점포들의 단순 평균을 계산합니다. 한 점포가 게시물을 많이 올려도 평균에 과도하게 반영되지 않도록 합니다.
- 할인가는 할인 적용 기간에만 사용합니다. 날짜 내 여러 가격의 평균인지, 마감 시점 가격인지 먼저 합의해야 합니다.
- 이력 변화가 없는 날은 유효한 가격을 유지하되, 상품 등록 전/판매 종료 후/관측 불가 기간을 임의로 채우지 않습니다.
- 데이터 없는 가격은 null로 반환합니다. 프론트에서는 0원으로 그리지 않고 선을 끊거나 누락 안내를 표시합니다.
- 예시로 보낼 숫자는 실측 데이터가 아니라면 별도 예시라고 명시합니다. 이력을 쌓기 전에는 실제 과거 가격 비교가 불가능합니다.

상품 상세에는 단위 필드가 아직 없으므로 단위 표시도 함께 협의해야 합니다.
