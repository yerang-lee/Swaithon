# 카카오 위치 설정

## 프론트엔드 설정

카카오 개발자 콘솔에서 팀이 관리할 앱을 만들고 카카오맵 사용 설정과 Web 플랫폼 도메인을 등록합니다.
JavaScript 키를 사용하며 REST API 키나 Admin 키를 앱에 넣지 않습니다.

`frontend/.env`에 다음 값을 입력한 후 Expo 서버를 재시작합니다.

```dotenv
EXPO_PUBLIC_KAKAO_MAP_KEY=발급받은_JavaScript_키
EXPO_PUBLIC_KAKAO_MAP_ORIGIN=https://localhost
```

네이티브 앱은 WebView + 카카오 JavaScript 지도 SDK를 사용합니다. WebView의 baseUrl과 등록한 사이트 도메인이 일치해야 합니다. 기본값은 `https://localhost`입니다. 콘솔이 해당 도메인을 허용하지 않거나 서비스 환경이 달라지면 실제 소유한 HTTPS 도메인으로 변경하고 실제 기기에서 확인해야 합니다.
웹 미리보기는 브라우저 주소(예: `http://localhost:8081`)도 별도 등록해야 합니다. 포트가 바뀌면 등록 주소도 확인하세요.
카카오 개발자 콘솔의 지도 사용 설정/허용 도메인과 실제 기기에서의 지도 노출은 키 발급 후 검증해야 합니다.

## 동작

- 저장 위치가 없으면 앱 사용 중 위치 권한을 요청해 GPS 좌표를 가져옵니다. 권한 거절 시 임의 위치를 현재 위치로 표시하지 않습니다.
- 초기 홈 동네명은 기기의 역지오코딩 결과를 사용합니다. 지도에서 선택/적용 시 카카오 행정동 결과로 갱신됩니다.
- 주소/키워드 검색을 350ms 지연해 카카오 서비스에 요청하고 결과를 선택하면 지도의 중심과 탐색 중심을 변경합니다.
- 검색 요청 순서를 확인해 이전 검색 결과가 최신 검색을 덮어쓰지 않도록 합니다. 서울 주요 동네의 초기 이름 후보 색인을 함께 사용해 망 → 망원동과 같은 짧은 검색을 지원합니다. 전국 자동완성은 미구현이며, 목록 외 지역은 카카오 검색 결과에 따릅니다.
- 반경 슬라이더는 1~5km, 기본 1km, 1km 단위이며 실제 지도 Circle의 미터 반경과 연결됩니다.
- GPS 버튼은 현재 위치를 새로 조회하고 중심/원을 이동합니다.
- 적용한 좌표, 동네명, 반경은 기기에 저장합니다. 뒤로 가면 변경사항은 적용하지 않습니다.
- 화면 중앙의 고정 핀을 기준으로 지도를 이동하면 탐색 중심과 원이 갱신됩니다. 이동 중에는 적용을 막고, 중앙 좌표의 주소와 행정동 조회가 끝나면 적용할 수 있습니다. 상세 주소와 홈 표시용 행정동을 분리합니다.
- 홈 상품/시장/가게는 아직 예시 데이터이며 실제 반경별 서버 필터는 미연결입니다.

공식 문서: https://apis.map.kakao.com/web/guide/ 및 https://apis.map.kakao.com/web/documentation/
