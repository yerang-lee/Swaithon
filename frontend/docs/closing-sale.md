# 마감 세일

홈의 마감 세일 버튼은 /closing-sale 화면으로 이동합니다. 한국 시간 오후 4시부터 자정 전까지 현재 할인 중이며 품절되지 않은 상품을 표시하는 임시 기준입니다. 할인 시작 시각으로 판별하지 않습니다. 오후 4시 이전에는 안내 문구를 표시합니다.

CSV에 있는 GET /markets/nearby 및 GET /products의 기존 market_id/is_on_sale/is_sold_out/page/size 필터를 사용하며 새로운 서버 필드는 가정하지 않습니다. 주변의 등록된 시장별로 전체 상품 페이지를 조회하며, 기본가보다 낮은 sale_price를 가진 상품을 표시합니다. 실제 할인 시작 시각에 따른 마감 세일 분류는 백엔드 상세 명세가 필요합니다. 여러 시장은 최대 3개씩 병렬 조회하고, 일부 실패 시 이미 조회한 상품과 재시도 안내를 함께 표시합니다. 검색은 조회한 상품명을 대상으로 합니다.

지도·주소·범위 설정은 홈과 동일한 LocationSettings 컴포넌트를 사용합니다. 저장 성공 후 공통 위치 변경 알림을 발행해 홈·시장 찾기·관심상품·거리 계산을 갱신합니다. 이전 라우트의 거리는 위치 변경 후 재사용하지 않고 새 위치 기준으로 조회합니다. 위치 변경은 검색 범위를 조정하며 특정 시장/가게/상품 자체를 변경하지 않습니다.

상품 이미지는 서버 image_url을 사용하며 누락/오류 시 회색 영역을 표시합니다. 하트는 기존 찜 API를 사용하고, 상품 선택은 공통 /products/[listingId] 화면으로 이동합니다. 이 화면의 지도 Modal은 공통 컴포넌트의 별도 SafeAreaProvider를 사용하고 하단 탭은 SafeAreaView 내부에 배치합니다.
