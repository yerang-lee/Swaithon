# 백엔드 없이 화면 테스트

Expo 개발 서버를 실행하고 로그인 화면 하단에서 **상인으로 테스트** 또는 **고객으로 테스트**를 누릅니다. 백엔드 서버 주소나 로그인 정보는 필요하지 않습니다. Expo 개발 서버 자체는 실행해야 합니다.

- 상인: 홈 상품 등록/수정 버튼 → 실제 기기 녹음 또는 녹음 없이 결과 테스트 → 결과 표시 → 사진 한 장 선택 → 모의 업로드 완료.
- 고객: 상인 홈 버튼이 숨겨지는지 확인합니다.
- 시장 찾기: GPS 권한 없이 테스트 위치에서 3개 시장을 보여줍니다. 시장 선택 → 가게별 목록/검색/더 보기(24개) → 상품별 카테고리/관심 버튼을 확인합니다.
- 테스트 모드에서 회원가입 폼도 시험할 수 있습니다. 계정 정보는 메모리에만 보관하고 비밀번호는 저장하거나 검증하지 않습니다. 상인 가입의 지도 SDK는 별도 외부 서비스이므로 간편 상인 테스트 버튼을 사용하면 지도 설정을 건너뛸 수 있습니다.
- 화면 아래 노란 테스트 표시의 종료를 누르면 세션과 관심 목록을 지우고 실제 서버 모드의 로그인 화면으로 돌아갑니다. 테스트 세션/사진/상품은 실제 서버로 전송하지 않습니다.

테스트 모드는 개발 빌드(__DEV__)에서만 작동합니다. EXPO_PUBLIC_MOCK_API=true를 지정하면 개발 실행 시 기본 활성화할 수 있으며 선택 사항입니다. 변경 시 Expo를 재시작합니다. 서버 오류 시 자동으로 테스트 모드로 전환하지 않습니다.

음성 분석은 실제 AI가 아니라 사과 3개/5,000원 등의 고정 예시이고 사진은 기기 선택·미리보기만 실제로 동작하며 서버 업로드는 생략합니다. 녹음 없이 결과 테스트는 마이크 없이 UI를 확인하는 기능입니다. 실제 녹음은 기기 마이크 권한이 필요합니다. 서버 인증·상품 저장·오디오 분석·파일 업로드의 정상 동작은 실제 서버에서 별도로 검증해야 합니다. 명시한 경로 이외 API는 테스트 모드에서 미지원 오류를 표시하고 서버로 요청하지 않습니다. 상품 상세/예약은 기존 예시 상품 미리보기 범위만 지원합니다.
