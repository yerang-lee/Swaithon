# 내 가게 상품 목록

마이페이지의 내 가게 보기와 상품 처리 완료의 내 상품 보기는 /my-store로 이동합니다. GET /stores/me/listings를 상인 Bearer 토큰으로 호출하며 user_id/store_id를 보내거나 /users/me에서 store_id를 조회하지 않습니다.

page 기본 1, size 기본 10/최대 100, 선택 is_sold_out은 false도 명시해서 전송합니다. 양의 정수 ID, 가격·재고·할인율, nullable category_id/sale_price/sale_quantity/sale_unit/stock_quantity/sale_rate 및 날짜·페이지 정보를 검증합니다. 401/403/422/500과 계정 전환 중 응답을 처리합니다.

화면은 진입/재진입 및 상품 변경 시 첫 페이지를 조회하며 더 보기로 다음 페이지를 가져옵니다. 상품은 listing_id로 상세 화면에 연결합니다. 본인 상품 목록에 관심 버튼과 거리를 표시하지 않습니다. 명세에 가게 이름·주소·image_url이 없으므로 별도 추측이나 상품별 이미지 API 추가 호출 없이 기본 사진 영역을 표시합니다. 기존 다른 가게 상세 화면은 유지합니다.


UI는 정사각형 상품 사진이 위에 있는 두 열 카드형이며 상품명, 정상가/판매가, 재고 수량을 표시합니다. 할인 판매가는 빨간색이고 품절 문구는 사진 위에만 표시합니다. 더 보기는 배경 없는 텍스트 버튼을 사용합니다. 사용자 확인에 따라 가게 정보 API가 없으므로 가게 이름·주소·대표 이미지를 추측하거나 추가 조회하지 않습니다. 상품별 image_url도 현재 목록 명세에 없어 기본 사진 영역을 유지합니다.
