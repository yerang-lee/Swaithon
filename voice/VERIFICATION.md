# 검증 결과

- 로컬 자동 테스트: **50 passed** (Python 3.13.2, 2026-11-06 작업).
- 30개 고정 추출값을 통한 서버 동작 + 20개 권한/검증/API/저장 테스트.
- 확인 전 변경 없음, 확인 후 한 번 실행, 다른 상점 변경 없음, 누락 질문,
  삭제 표시, 품절, 할인 유지, 후보 선택, 만료, 동시 수정, 재시작 후 복원 확인.
- Python 소스 컴파일 확인.
- Colab 노트북 생성 완료. 로컬에서 코드 셀 문법/내장 소스 무결성을 검사.

테스트는 **기대 추출값을 주입한 서버 검증**입니다. 실제 Gemini/Whisper 정확도 수치는 아닙니다.
Gemini 키/모델 ID가 현재 환경에 없고 FFmpeg도 없어 실제 호출·녹음 전사는 실행하지 않았습니다.
모델을 새로 학습하거나 모델 가중치를 저장하지 않았습니다.
원래 Colab에 접근하거나 수정하지 않았습니다. 제공한 ipynb는 업로드 가능한 로컬 파일입니다.

FastAPI의 현재 Starlette 테스트 클라이언트에서 httpx 사용 중단 예정 경고 1건이 있었으나 테스트는 통과했습니다.
Windows의 제한된 실행 환경에서 HTTP 테스트 내부 연결이 멈춰, 허용된 실행 환경으로 재실행하여 검증했습니다.
운영 PostgreSQL·실제 로그인·앱 화면은 미연동입니다.

재검증: `python -m pytest tests -q`
실제 LLM 평가(환경변수 설정 후): `python tools/evaluate_gemini.py --run --limit 5`
전체 30개 평가: `python tools/evaluate_gemini.py --run --limit 30`
상대 날짜는 별도 수동 평가이며 점수는 지정 필드 부분 일치입니다.
