## 직접 해야 할 순서

1. VS Code에서 voice/README.md를 열고 가상환경과 requirements.txt 설치.
2. pytest 테스트를 실행하고 fixture 데모로 등록→수정→삭제 확인을 시험.
3. Google AI Studio에서 본인 Gemini API 키 준비. 사용 가능한 모델 ID 선택.
   키를 채팅에 보내지 말고 로컬 환경변수/Colab Secrets에 저장.
4. Gemini 모드에서 동일 명령과 새로운 표현들을 실제로 시험. 잘못된 추출은 tests에 추가.
5. Colab에서 notebooks/jangboso_voice_v1.ipynb를 업로드해 열기.
   기존 지정 Colab에는 이번 로컬 작업에서 접근/수정하지 않았음.
   기존 노트북을 유지하려면 이 노트북 셀을 복사하고 원본 셀은 보존.
6. Colab의 설치→내장 소스 복원→규칙 테스트→Secrets→Gemini 분석→녹음 업로드 순서로 실행.
7. 녹음 20개 이상(조용한 곳/시장 소음/가격 정정)을 직접 준비하고 결과 확인.
   현재 노트북은 학습이 아니라 사전학습 모델 추론·평가용. 학습 가중치는 생성하지 않음.
8. BACKEND_HANDOFF.md를 백엔드 담당자에게 전달하고 상점 소유권/상품 모델을 확정.
9. 운영 PostgreSQL 어댑터와 인증 의존성을 연결하고 실제 DB 통합 테스트.
10. FRONTEND_HANDOFF.md에 따라 앱 녹음·질문·확인·목록 갱신 연결 후 실기기 테스트.
